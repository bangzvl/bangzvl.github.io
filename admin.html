Admin iklan

Ganti kode iklan Adsterra di aplikasi tanpa membuka GitHub. Perubahan tampil di aplikasi sekitar 1–2 menit setelah disimpan, saat aplikasi dibuka lagi.

Masuk

Admin memakai token GitHub milikmu. Token hanya disimpan di browser ini dan dikirim langsung ke GitHub.

Cara membuat token (sekali saja)
  1. Buka github.com/settings/personal-access-tokens/new.
  2. Nama token: Admin iklan MLBB Academy. Masa berlaku: misalnya 1 tahun.
  3. Repository access: Only select repositories → pilih bangzvl/bangzvl.github.io.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Klik Generate token, salin, lalu tempel di kolom di atas.
