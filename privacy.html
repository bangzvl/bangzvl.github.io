Kebijakan Privasi MLBB Academy

Berlaku sejak: 14 November 2026 · Pengelola: bangzvl · Kontak: introtoolsml@gmail.com

MLBB Academy adalah aplikasi penggemar (fan app) yang tidak berafiliasi dengan, tidak didukung oleh, dan tidak dioperasikan oleh Moonton. Mobile Legends: Bang Bang beserta nama, gambar, dan asetnya adalah milik Moonton.

1. Data yang disimpan di perangkatmu

Aplikasi menyimpan data di penyimpanan browser/perangkatmu sendiri (localStorage) agar lebih cepat: salinan data hero, item dan jadwal, daftar hero favorit, pilihan tampilan, serta ID Game dan Server terakhir yang kamu masukkan. Data ini tidak dikirim ke server kami. Kamu bisa menghapusnya lewat menu Lainnya → "Hapus data tersimpan".

2. Data game (hero, item, esport)

Data publik Mobile Legends diambil dari layanan pihak ketiga Rone Arena (arena.rone.dev). Saat memuat data, alamat IP dan informasi teknis standar perangkatmu terlihat oleh layanan tersebut sesuai kebijakan mereka.

3. Masuk dengan akun MLBB (opsional)

Jika kamu memilih masuk di halaman Profil, ID Game, Server, dan kode verifikasi dikirim ke Rone Arena untuk diteruskan ke layanan Moonton guna memverifikasi kepemilikan akun. Token sesi yang dihasilkan disimpan hanya di perangkatmu dan dihapus saat kamu menekan "Keluar". Kami tidak menyimpan kode verifikasi maupun data akunmu di server kami.

4. Notifikasi (OneSignal)

Jika kamu mengaktifkan notifikasi, layanan OneSignal menyimpan ID langganan perangkat, jenis browser/perangkat, bahasa, zona waktu, dan topik yang kamu pilih (misalnya "esport") untuk mengirim notifikasi. Kamu bisa mematikannya kapan saja di Lainnya → Notifikasi atau di pengaturan perangkat. Lihat kebijakan privasi OneSignal.

5. Iklan (Adsterra)

Aplikasi menampilkan iklan dari Adsterra. Penyedia iklan dapat mengumpulkan informasi seperti alamat IP, jenis perangkat, dan interaksi dengan iklan untuk menayangkan dan mengukur iklan. Lihat kebijakan privasi Adsterra.

6. Anak-anak

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun dan kami tidak dengan sengaja mengumpulkan data pribadi anak.
